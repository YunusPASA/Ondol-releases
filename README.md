# Ondol (Beta)

**A desktop companion and study buddy for Windows.**

This repository holds the downloads of Ondol and its issue tracker. The source code is not published here.

## Download

Get the newest version from [Releases](https://github.com/YunusPASA/Ondol-releases/releases/latest):

- `Ondol-Beta-win-x64-setup.exe`: the installer (per user, no administrator rights)
- `Ondol-Beta-win-x64.zip`: the portable version (unzip and run `Ondol.exe`)

Windows 10 (1809 or newer) or Windows 11, 64-bit. The program is not code-signed, so Windows may show "Windows protected your PC": choose **More info → Run anyway**.

Ondol does not connect to the internet unless you ask it to look for an update, and it never sends anything about you.

## Report a problem

Open an [issue](https://github.com/YunusPASA/Ondol-releases/issues/new), or use **Report a problem** in Ondol's tray menu, which fills in the versions for you.
